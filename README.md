# Coin Keep

A small original browser game: walk your king, let your squad auto-shoot, collect the gold enemies drop, and spend it on green pads for soldiers, archer towers (upgradable to fire gunners), walls, artillery, fire weapons and keep upgrades that expand your base.

Play: https://delta2oscar.github.io/coin-keep/

- Phone: drag anywhere to move. Desktop: WASD / arrow keys or mouse drag. P or Esc pauses.
- Single self-contained `index.html`, no external assets or network calls. Works offline after the first visit and can be installed from Chrome's menu (Add to Home screen / Install app).
